Reflections:
-	Slow is smooth, smooth is fast. Slow and steady progress that builds upon each step is the most effective way (for me) to learn new concepts, build things out, and make progress. I don’t always practice this and it bites me every time.
-	There’s a library or plugin for almost everything, working with NetworkX is fantastic and made the graph creation, traversal, etc. much easier. It also highlighted the importance of understanding what’s underneath the hood. I was imagining working through this without having done data structures and it made me want to document the project / update it without the libraries eventually.
-	There is a learning curve to new libraries / tools but the right tools make all the difference in terms of ease of implementation.
-	Modular design principles allow for easy replication. Thoughtful architecture design before you start coding is essential.
